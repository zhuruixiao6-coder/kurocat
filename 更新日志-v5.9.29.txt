KuroCat v5.9.29 · 更新日志
========================

版本日期：2026-11-27
主题：自由走动 + 四个新动作

一、自由走动（本次核心）

· 菜单「外观与互动」新增「自由走动」开关，点击循环切换：
  关闭 → 自主巡逻 → 跟随鼠标 → 关闭；
· 自主巡逻：空闲时猫猫在桌面上随机走动，走一段歇一段，
  走到屏幕边缘会自动转身，不会跑出可视区域（复用窗口拖拽的边界约束）；
· 跟随鼠标：猫猫朝光标所在方向走动，光标居中时停下（带死区）；
· 走动时有真实的步态动画：四肢交替迈步、身体轻微起伏、尾巴反向配重，
  并会侧身朝向前进方向；
· 打字、拖拽、摸猫、睡眠、隐私模式下自动暂停走动，不打扰正常交互；
· 窗口移动经 Rust 命令执行，带屏幕边界钳制；Win7 ULW 分层窗口模式自动禁用。

二、新增四个动作（进入空闲随机池 + 部分可手动触发）

· 打滚翻肚皮（rollOver）：侧身倒下 → 翻身露肚皮 → 四爪朝天蹬动 → 翻回趴好；
· 挥爪打招呼（wave）：抬起右爪左右摆三下 → 歪头眯眼 → 收爪；
· 跳舞（dance）：跟着节奏左右摇摆、点头晃脑、尾巴打拍子；
· 追激光笔（laserChase）：头随光标转向锁定 → 突然扑击 → 扑空甩头 → 不甘再盯；
· 这四个动作已加入空闲自动玩耍的随机池，与原有 9 个动作一起随机出现。

三、技术实现

· catEngine3d.ts：新增 PlayKind3D 四个成员 + 四段式姿态曲线；
· 新增走动状态机 setWalkMode / updateWalk / setWalkMoveHandler / setWalkScale；
· 新增 Rust 命令 move_pet_by（工作区边界约束 + 拖拽互斥 + Win7 分支）；
· 设置项 walkMode 全链路贯通（前端 ↔ Rust config，camelCase 自动映射）；
· 版本号 5.9.28 → 5.9.29（package.json / tauri.conf.json / Cargo.toml）。
